Calculo del conjunto FIRST
1. Simbolo S (Produccion S -> AB):
    - s depende de FIRST(A) y FIRST(B)
    - Se calula primero FIRST(A)
2. Simbolo A (Produccion -> Ca | ε)
    - Para A -> Ca
        - FIRST(c) se calcula
        - C -> b | ε, por lo que FIRST(C) = {b, ε}
        - Como ε esta en FIRST(C), se agrega a de Ca.
        - Resultado parcial FIRST(A) = {b,a}
    - Para A -> ε
        - Se agrega directamente ε
        - Resultado final: FIRST(A) = {b, a, ε}
3. Simbolo B (Produccion cX)
    - c es terminal, por lo que
        FIRST(B) = {c}
4. Simbolo X (Produccion: X -> aACX | ε)
    - Para X -> aACX:
        - a es terminal, por lo que:
        - FIRST(X) = {a}
    - Para x -> ε
        - Se agrega ε directamente
        - Resultaado final: FIRST(X) = {a, ε}
5. Simbolo C (Produccion: C -> b | ε):
    - C deriva b o ε, por lo que 
        - FIRST(C) = {b, ε}

Conjunto FOLLOW
1. Simbolo S:
    - S es el simbolo inicial.
    - Se agrega $( fin de entrada ) a FOLLOW(S):
2. Simbolo A (Produccion S -> AB)
    - A esta seguido por B en la produccion
    - Se agrega FIRST(B) (sin ε) a FOLLOW(A).
    - FIRST(B) = {c}, por lo que FOLLOW(A) = {c}
    - Ademas FOLLOW(s) se propaga a A ya que B puede derivar ε (X -> ε en B -> cX)

3. Simbolo B
    - FOLLOW(B) hereda FOLLOW(S)

4. Simbolo X (Produccion: B -> cX)

5. Simbolo A (Produccion: X -> aACX):
    - A esta seguido por C en X -> aACX
    - Se agrega FIRST(C) = {b, ε} a FOLLOW(A).
    - Como ε esta en FIRST(C), se agrega FOLLOW(X) a FOLLOW(A)
        - FOLLOW(A) = {c, b, a, $}
6. Simbolo C (Produccion A -> Ca)
    - C esta seguido por a en A -> Ca, por lo que   
        - FOLLOW(C) = {a}
    - Ademas FOLLOW(A) se propaga a C ya que A -> ε es posible
        - FOLLOW(C) = {a, $}

A : {'b', 'c', '$', 'a'}

- FOLLOW(A) = {b, c, $, a}

    - En X -> aACX, A esta seguido por C. Dado que C -> ε es posible, FOLLOW(X) = {$} tambien se agrega a FOLLOW(A)

- FOLLOW(C) = {a, $}
    - C aparece en A -> Ca, por lo que FOLLOW(C) incluye el terminal a.
    - Ademas, A -> ε implica que FOLLOW(A) se propaga a C, lo que añade $ a FOLLOW(C).
